# 📝 To-Do List App

A responsive To-Do List web application built using HTML, CSS and JavaScript.

This project was created to strengthen my understanding of JavaScript DOM manipulation, event handling and browser storage.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Dynamic progress bar
- Completion percentage
- Confetti animation when all tasks are completed 🎉
- Local Storage support
- Tasks remain after refreshing the browser
- Responsive design for mobile and desktop
- Custom favicon

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Font Awesome
- Canvas Confetti

## 📱 Responsive Design

The application is designed to work across:

- Mobile phones
- Tablets
- Laptops
- Desktop screens

## 🎯 What I Learned

Through this project, I practiced:

- Selecting and manipulating DOM elements
- Creating HTML elements dynamically
- Event listeners
- Form submission
- JavaScript functions
- Array methods
- Local Storage
- Conditional rendering
- Responsive CSS
- Basic UI/UX principles
